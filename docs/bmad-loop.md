# BMAD autonomous story loop

Trial on branch `bmad-trial` (2026-08-25). Mirrors the overnight loop from
"How I Built a Full App Solo in 100 Days — BMAD + AI Agents": orchestrator →
fresh-context agent per story → build-auto (plan, implement, parallel
reviewers, fix, commit) → verify → headless retrospective → course-correct docs.

## Pieces

| Piece | Where |
|---|---|
| Spec kernel + companions | `_bmad-output/specs/spec-<slug>/SPEC.md`, `touchpoints.md`, `.memlog.md` |
| Story list (execution order) | `_bmad-output/specs/spec-<slug>/stories.yaml` |
| Per-story spec + result | `_bmad-output/specs/spec-<slug>/stories/<id>-*.md` (written by build-auto) |
| Orchestrator | `.claude/workflows/bmad-story-loop.js` (Claude Code Workflow) |
| Retrospective | `_bmad-output/implementation-artifacts/` |

## Run one epic overnight

1. Spec it: `/bmad-spec create a spec from <input>`; answer open questions; write `stories.yaml` (or accept the Story Breakdown offer).
2. Provision a worktree (build-auto refuses a dirty tree):
   ```bash
   git worktree add -b <loop-branch> ../Banhall-<loop> <base-branch>
   cd ../Banhall-<loop>
   ln -s ../Banhall/node_modules node_modules
   cp ../Banhall/.env.local .
   npx svelte-kit sync
   npm test -- generationRecovery   # sanity
   ```
3. Launch:
   ```
   Workflow name "bmad-story-loop" with args
   {"worktree":"/abs/path/Banhall-<loop>","specFolder":"_bmad-output/specs/spec-<slug>",
    "storyIds":["1","2",...],"epicLabel":"<slug>","date":"YYYY-MM-DD"}
   ```
   Stories run sequentially because they overlap on files; parallelize only
   disjoint epics in separate worktrees.
4. Morning: `git log bmad-trial..<loop-branch>`, read the retrospective and
   each story's `## Auto Run Result` (deferred items live in frontmatter),
   fix, then merge or cherry-pick.

## Gotchas found on first run

- `npx bmad-method install -y` still prompts; needs a TTY (`expect` with
  `stty columns 120`). Needs `uv`.
- `_bmad/render/` is generated by `render_skill.py`; ignored in `.gitignore`.
- Worktrees need `svelte-kit sync` before vitest (tsconfig extends `.svelte-kit/`).
- `bmad-help` catalog CSV mis-parses rows with commas in descriptions.
- Every BMAD skill is interview-first; headless means the orchestrator makes
  the calls the skill wants from a human and logs them as assumptions.
