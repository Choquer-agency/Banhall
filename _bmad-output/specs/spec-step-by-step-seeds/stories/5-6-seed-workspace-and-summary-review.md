## Intent

**Problem:** Stories 0–4 provide the backend, but writers cannot complete the Seed-to-report journey in the app.

**Approach:** Deliver stories 5–6 together: Seed workspace, Summary Review, sign-off, recovery, signed-off Summary and Brief labels. Connect new iterative requests after both screens are integrated.

**UI (owner amendment, 2026-09-24):** Every screen follows `ui-design-final.md` (Paper page "Final screens", approved by the owner and shown to clients). It replaces all earlier visual and interaction descriptions in this story. Scope now also covers the writing view, background QA and report layout controls (CAP-17, CAP-18, CAP-19; PRD FR-42 to FR-45).

## Boundaries & Constraints

**Always:** Follow CAP-2/4–12/14/16/17/18/19, AD-31/35/36/40/41/44 and `ui-design-final.md`. Render server states, challenges and readiness; preserve pagination and version fences. Reuse permissions, primitives, tokens and max weight 500. Preserve per-user unsaved drafts across navigation and conflicts.

**Ask First:** New domain semantics, permissions, AI calls or prose-writing paths.

**Never:** Compute readiness/staleness on the client; auto-select revisions or regenerate stale work; mutate frozen plans; change single/compare or existing section-approval runs. Stories 7–8 remain separate.

## I/O & Edge-Case Matrix

| Scenario | Input | Expected | Failure |
|---|---|---|---|
| Workspace | New iterative request | Initialize Seeds; navigate thirteen roles | Initialization retry; no ghost/legacy stepper |
| Decisions | Edit, feedback, regenerate, skip, restore | Existing reversible mutations; revisions unselected | Preserve drafts on refusal/conflict |
| Approval | Carried/exclusion-matching selections | Server challenge with exact acknowledgments | Refresh changed challenge; no inferred consent |
| Summary | Live plan, multiple items/pages | Full in-page review; edit withdraws readiness; frozen settings | Label partial results; block incomplete sign-off |
| Sign-off | Current ready version | Drafting chain, editor, read-only frozen Summary | Show blockers; retry same Summary on draft failure |
| Access/layout | Read-only user or narrow viewport | No mutation controls; keyboard-operable one-pane layout | Preserve focus and announce errors |
